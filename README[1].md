Computational Research Projects

This repository contains bioinformatics workflows and analysis code across 
two phases of research. Manuscripts for current projects are in preparation.

Current Projects (2025–26)

1. Comparative Metagenomic Analysis of Antibiotic Resistance Genes
Hospital wastewater vs. environmental water samples, India.
Methods: Metagenomic pipeline, ARG profiling, comparative analysis.
Status: Manuscript in preparation.

2. Machine Learning Classification of HCC Biomarkers
Transcriptomic data analysis for hepatocellular carcinoma biomarker identification.
Methods: Feature selection, ML classification, transcriptomic datasets.
Status: Manuscript in preparation.

3. Multi-Epitope Vaccine Design Against Hantavirus
Computational vaccine candidate using ML and immunoinformatics.
Methods: Epitope prediction, docking, immune simulation.
Status: Manuscript in preparation.

4. Network Pharmacology Analysis of Ag-Au Bimetallic Nanoparticles
Target identification against MDR bacteria via PPI networks and pathway enrichment.
Methods: Network pharmacology, PPI construction, GO/KEGG enrichment.
Status: Manuscript in preparation.
