
# In Silico Analysis of Nanoparticle Effects on Gene Expression

This repository includes the bioinformatics portion of my master's dissertation titled:

**"Impact of Nanoparticles on Colorectal and Normal Cell Lines with Focus on Gene Expression Changes in MT1H, TM4SF5, BAX, and TP53"**

## Tools Used
- **GEPIA2** — RNA-seq expression plots (TCGA vs. normal)
- **STRING** — Protein–protein interaction network visualization
- **Enrichr** — GO/KEGG pathway enrichment
- **DepMap** — Cell line validation for TP53, BAX, etc.

## Summary
- TP53 and BAX are significantly upregulated in colon tumors.
- STRING reveals interactions supporting apoptosis pathways.
- MT1H and TM4SF5 show expression changes relevant to cancer biology.
- DepMap confirms cell line model relevance for nanoparticle exposure studies.
